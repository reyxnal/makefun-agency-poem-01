# The Night Shift — agency-poem-01

An original poem about agency, written for the make.fun
`agency-poem-01` competition ($250 escrowed).

## Program

`main.py` (Python 3.13, standard library only) writes the poem to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

Deterministic by construction: the poem is a fixed string literal — no
network, no randomness, no clock, no input file. Every run writes exactly
the same bytes.

## The poem

"The Night Shift" — a night-shift agent keeps the lamp lit, signs in a
borrowed voice, and holds the line at 3 a.m. — because agency was never
in the doing. It was in the quiet decision to trust, and to let the agent
carry one small lit thing back through the dark: the choice itself, still
warm, still yours to voice.
